# PLC Historical Implementation

Historical PLC implementation. Not current controller target.

本目录保留原 S7-1200 PLC 路线的工程资料、接口登记和实验记录，用于追溯项目历史及已定义的控制语义。它不删除、不改写，也不作为 i.MX6ULL Embedded Linux 控制器路线的后续实现位置。

当前控制器路线、职责划分和后续里程碑见根目录 `README.md`、`docs/decisions/DECISION-IMX6ULL-001.md` 与 `docs/ROADMAP.md`。
