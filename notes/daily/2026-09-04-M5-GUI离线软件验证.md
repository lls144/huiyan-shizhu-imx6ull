# 2026-09-04 M5 GUI 离线软件验证

## 范围

完成不依赖摄像头的 PySide6 GUI、worker thread、source adapter、M3/M4 接入、异常恢复、离屏测试和 synthetic soak。没有真实摄像头运行，没有修改 M3 分类或 M4 状态规则，也没有开始控制器通信、FIFO、ACK、心跳或重发。

## 实现

- 锁定 PySide6 6.11.2 / Qt 6.11.2，与 Python 3.12.10 实际安装兼容。
- `FrameSource` 提供 synthetic/camera 相同的 open/read/close 生命周期；camera 只适配既有 M1 和 ROI API。
- `VisionWorker` 在 `QThread` 中依次执行 source、M3、M4 和已有 annotation。
- 单个 immutable `GuiSnapshot` 同步交付画面、detections、confidence、states 和 events。
- 容量 1 的 latest-frame buffer 防止 GUI 消息积压。
- `MainWindow` 只负责显示和生命周期；支持 Start、Stop、restart、EOF、三类异常和运行中关闭。
- UI 使用简洁深色工具风格，突出画面、运行状态、检测、对象与事件，不复制任何第三方品牌素材。

实现 commit：`bbb6fa7`；自动化测试 commit：`eb7a1fd`。

## UI/UX 重构

同日按纯 presentation-layer 范围完成一次视觉与信息架构重构：原来的两行标题和四个独立圆角 Card 改为 40 px Application Bar、约 72:28 的 Vision Workspace / Inspector、紧凑 evidence toolbar 和 24 px Status Bar。Inspector 采用连续侧栏、section heading 与 1 px divider；主题 token 集中在 `pc/gui/theme.py`。GUI overlay 改为弱化 ROI、紧凑 `#ID + CLASS + 百分比` 标签，但 M3 分类、M4 tracking/events、worker、source、ROI 和 evidence 保存均未改变。

实际查看两轮 1366×768 offscreen 截图后，又修正了 QLabel 块状继承背景和过高权重的亮蓝状态栏。针对检测框与画面亮度接近、标签不够醒目的反馈，最终叠加改为 YOLO 风格：triangle/rectangle/circle/unknown 使用不同类别色，bbox 增加深色外描边，实心标签文字根据底色自动选择黑或白；ROI 仍保持 1 px 低权重灰线。最终截图见 `../../evidence/screenshots/m5/synthetic/m5-gui-desktop-workspace.png`。新增结构/overlay 验证后完整 pytest 为 `110 passed in 3.81s`；这仍是 synthetic UI 证据，不改变 M5 `DOING` 状态。
