# 2026-09-10 M9 i.MX6ULL 实机部署与 TCP 验证

今天在真实野火 i.MX6ULL（Debian 10、armv7l、Python 3.7.3）完成最小 Controller 部署。Ubuntu dev-host 通过 USB Gadget Ethernet 的 `198.51.100.2:9000` 进行了真实 TCP 验证，不是 localhost、Mock 或 Fake PLC。

- 实现 commit：`9906133a6db4e5391704fadf3c3b94b0b893b765`。
- Python 3.7 改造、17 文件最小 SCP 清单、板端 compileall、直接入口和 10 项 TCP smoke 均已通过。
- GPIO 配置保持 `null`；`GpioKeyInput` 返回 `NOT_CONFIGURED`，未操作未知 GPIO。
- 本记录形成时 M9 只能记为 DOING：物理按键/输出/接线验证尚未开始，等待真实 GPIO chip/line、极性和接线确认。

详见 [[../tests/TEST-008-M9-iMX6ULL部署与TCP验证]] 和 `docs/IMX6ULL_DEPLOYMENT.md`。

> 后续更新：实体 GPIO 三按键输入和 FSM 闭环已在 TEST-009 通过；实体 LED 输出在 TEST-010 通过；PC vision 到实体 LED 闭环在 TEST-011 通过。本记录的 TCP `key_event` 注入不替代任一实体证据。批准的 i.MX6ULL M9 路线现为 DONE。
