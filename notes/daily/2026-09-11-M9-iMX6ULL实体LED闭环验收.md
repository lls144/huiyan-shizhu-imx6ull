# 2026-09-11 M9 i.MX6ULL 实体 LED 闭环

今天完成并人工观察了受限 LED helper 的实体 RGB 输出，以及普通用户 Controller 经 Unix socket 的实体按键/FSM/LED 闭环。Branch1/2/3 分别产生 red、red+green、red+green+blue，均约一秒后全灭；错误工位、enqueue 和普通站点移动不点灯，reset 后全灭。

完整环境、权限边界、原始 input code 149/202、brightness 时间序列和限制见 `notes/tests/TEST-010-M9-iMX6ULL实体LED闭环验收.md`。后续同日的 PC vision 到实体 LED 端到端验收见 TEST-011；批准的 i.MX6ULL M9 路线现为 DONE，M10 未开始。
