## 工作流

1. 开始前阅读 `AGENTS.md`、`docs/PROJECT_SPEC.md` 和当前 milestone。
2. 复制 Daily 模板到 `daily/`，记录当天目标和环境。
3. 测试前复制 Test 模板到 `tests/`，先填写预期与条件，再执行。
4. 出现问题时在 `issues/` 建立唯一 ISSUE，并从 Daily/Test 双向链接。
5. 重要设计选择写入 `decisions/`，不要把选择写成老师原始要求。
6. 测试后更新 `docs/REPORT_EVIDENCE.md` 并提交 Git。

## 当前待确认 / 未完成范围

- 实际 CPU 已确认为 1214C DC/DC/DC；完整订货号、在线固件、TIA 环境可用性、PLC IP/端口和 I/O 分配仍待真实核实。
- 最终选择串口还是以太网。
- “单向通信”与“超时重发/队列满通知”的返回机制如何兼容。
- 真实 PLC 路线仍须由负责人和 PLC 同学按 `docs/PLC_INTERFACE.md` 冻结形状编码、帧边界、ACK、幂等、心跳与队列满语义；i.MX6ULL Controller 协议的完成不等于该接口已冻结。
- M9 的批准 i.MX6ULL 路线已完成；后续 M10 仍须单独授权并验收，真实 PLC 路线仍独立 TODO。见 `docs/IMX6ULL_DEPLOYMENT.md`。
- 纸板样本尺寸/编号、白色背景板是否严格 A3 及材质仍未单独登记。
- 任务书进程表缺失的阶段名称和序号。
