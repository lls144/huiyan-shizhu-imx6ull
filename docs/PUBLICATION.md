# 公开版本说明

本仓库保存经过隐私整理的项目开发历史、源码、配置模板和工程记录。原始 PR、讨论以及未经公开筛选的材料留在私有归档，不在此仓库重新发布。

## 整理范围

- 从各历史版本移除课程原始 Word 文档和无工程展示价值的人像图；现场截图中的人员画面使用不透明遮挡，保留 GUI 状态与日志。
- 现场 IP 改为 RFC 5737 文档网段，MAC、USB 摄像头实例标识和个人本地路径作替换。它们是示例标识，连接设备前必须配置现场值。
- 保留工程测试计数、错误与未完成项，不用合成数据替换真机测量。标记为 synthetic / Fake PLC 的素材只用于离线测试。
- 历史作者归一为公开账号或匿名协作者，仍保留协作贡献区别；历史提交 ID 随脱敏改写。旧笔记中的原提交号只用于对照私有归档。
- 实验照片重新编码并去除元数据。新增图片是实际设备和现场记录，不是生成图。

## 来源与使用

项目源码按原模块保留作者与已有来源说明。依赖 OpenCV、PySide、NumPy、python-snap7 等组件，安装与分发须遵循各自上游许可证；仓库未给这些第三方组件重新授权。未额外附带课程课件、教材或安装包。

i.MX6ULL overlay 中的少量 pinfunc 常量注明了 Embedfire `ebf-linux-dtoverlays` 上游来源；Linux input key code 沿用内核定义。相关注释随代码保留。

公开代码用于学习和复现当前工程。公开可读不等于为所有第三方材料授予额外许可；需要再分发时请核对具体文件及上游条款。
