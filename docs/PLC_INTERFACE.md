## 不得降低的任务要求

需求来源 `PROJECT_SPEC.md`：FIFO 容量 ≥3；按键逐条出队；三类形状对应 1/2/3 盏 LED；队列空/满/长度与复位；PC 每秒心跳，PLC 中断 2 秒全灯闪烁；超时重发与队列满通知。单向业务与返回通知的歧义继续按规格中的澄清要求处理。
